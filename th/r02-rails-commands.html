คำสั่ง Rails

คุณจะพิมพ์คำสั่งเหล่านี้ทุกวัน กด ▶ รัน ในแต่ละ terminal เพื่อดูคำสั่งและผลลัพธ์ที่เหมือนของจริง

ให้รัน bin/rails จากโฟลเดอร์โปรเจกต์เสมอ มันใช้ Rails เวอร์ชันของโปรเจกต์ตาม Gemfile ไม่ใช่เวอร์ชันที่ติดตั้งไว้ในเครื่อง พิมพ์แค่ rails ในโปรเจกต์ก็ได้ เพราะมันจะส่งต่อให้ bin/rails

rails server

เปิด Puma ที่ port 3000 และ reload โค้ดทุก request ในโหมด development

rails console

Ruby แบบโต้ตอบที่โหลดแอปทั้งหมดไว้แล้ว เป็นวิธีที่เร็วที่สุดในการลอง query หรือตรวจข้อมูล

rails generate model

สร้าง model, migration, test และ fixture ในคำสั่งเดียว รูปแบบของ field คือ name:type:modifier

typeใช้กับ
textชื่อ คำอธิบาย บน Postgres เราใช้ text แทน string (ไม่จำกัดความยาว ความเร็วเท่ากัน)
booleanค่า flag ต้องกำหนด default เสมอ: is_admin:boolean แล้วแก้เป็น default: false
integer / decimalจำนวนนับ / เงิน (price:decimal{12,2})
datetime / dateเวลา เช่น deleted_at, locked_at
jsonbpayload ดิบจากระบบภายนอกที่เก็บไว้ตามเดิม
referencesforeign key: user:references
:index / :uniqmodifier ที่เพิ่ม index / unique index

rails generate migration

ใช้แก้ตารางที่มีอยู่แล้ว Rails อ่านชื่อ migration: AddXToY และ RemoveXFromY จะเติมโค้ดให้ล่วงหน้า

rails generate controller

rails destroy

ยกเลิกสิ่งที่ generator สร้าง ลบเฉพาะไฟล์ที่มันสร้างไว้ ให้รันก่อน migrate หรือ rollback ก่อน

rails routes

แสดงทุก route พร้อมชื่อ helper กรองด้วย -g (grep) หรือ -c (controller) บท r09 อธิบายวิธีอ่าน

rails test

rails credentials แยกไฟล์ตาม environment

secret (รหัสผ่าน service account, JWT secret, API key) ถูกเข้ารหัสเก็บไว้ใน repo เราไม่ใช้ master.key ไฟล์เดียว แต่ละ environment มีไฟล์เข้ารหัสและ key ของตัวเอง นักพัฒนาที่มี key ของ development จึงอ่าน secret ของ server dev ไม่ได้

config/credentials/
├── development.yml.enc   # committed: encrypted secrets for your laptop (RAILS_ENV=development)
├── development.key       # NOT committed: decrypts development.yml.enc
├── dev.yml.enc           # committed: our shared dev server (RAILS_ENV=dev)
├── dev.key               # NOT committed: only people who deploy dev have it
├── test.yml.enc          # committed: fake values for bin/rails test
└── test.key              # NOT committed: on every laptop and in CI secrets
Rails อ่านไฟล์ไหน?เลือก environment
Rails.application.credentials.dig(:directory, :username)  # nil if missing
Rails.application.credentials.user_jwt_secret            # top-level key
Rails.application.credentials.user_jwt_secret!           # raises KeyError if blank
ห้าม commit ไฟล์ .key ห้ามวางในแชท และห้ามใส่ใน Docker image ตรวจด้วย git check-ignore -v config/credentials/dev.key ถ้า key รั่ว ให้เปลี่ยน secret ทุกตัวในไฟล์นั้น แล้วเข้ารหัสใหม่ด้วย key ใหม่

rails runner

สรุปคำสั่ง

คำสั่งทำอะไร
bin/rails sเปิด server
bin/rails c [--sandbox]console (sandbox จะ rollback)
bin/rails g model Name field:typemodel + migration + test + fixture
bin/rails g migration AddXToY x:typeเปลี่ยน schema ของตารางที่มีอยู่
bin/rails g controller api/v1/admin/thingscontroller + test (แล้วแก้ class แม่)
bin/rails destroy …ยกเลิกสิ่งที่ generator สร้าง
bin/rails db:migrate / db:rollbackรัน / ยกเลิก migration (r03)
bin/rails routes -g nameหา route และชื่อ helper (r09)
bin/rails test [file[:line]]รัน test (r10)
bin/rails credentials:edit -e devแก้ secret ที่เข้ารหัสของ environment หนึ่ง
bin/rails runner 'code'รัน Ruby โดยโหลดแอปไว้

อยากลองลบ record จริงใน console เพื่อดูผล โดยไม่ให้การเปลี่ยนแปลงค้างอยู่ ต้องรันคำสั่งอะไร?

--sandbox rollback ทุกอย่างเมื่อออกจาก console
