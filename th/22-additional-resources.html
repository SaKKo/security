22 · แหล่งข้อมูลเพิ่มเติม

ความรู้ด้านความปลอดภัยล้าสมัยเร็ว แหล่งข้อมูลดีๆ ไม่กี่แห่งช่วยให้เราทันอยู่เสมอ

ติดตามข่าวสารของ stack เรา

  • ประกาศความปลอดภัยของ Rails: กดติดตามไว้ นี่คือที่ที่ CVE ของ Rails ปรากฏเป็นที่แรก
  • Rails Security Guide (พื้นฐานของคู่มือนี้ส่วนใหญ่) และ OWASP Ruby on Rails Cheat Sheet
  • ruby-advisory-db (สิ่งที่ bundler-audit ตรวจ) และการแจ้งเตือน Dependabot ของ GitHub บน repo ของเรา
  • ประเภทคำเตือนของ Brakeman: แต่ละคำเตือนหมายถึงอะไร และแก้อย่างไร

OWASP

  • OWASP Top 10:2025: รายการความเสี่ยงเว็บที่ร้ายแรงในปัจจุบัน (มีแผนที่ในหน้าแรก)
  • OWASP Cheat Sheet Series: คู่มือสั้นๆ ใช้งานได้จริงในแต่ละหัวข้อ เริ่มจาก XSS และ Authorization
  • Cheat sheet จัดตามหมวด Top 10 (จัดตามฉบับปี 2021)

Mozilla และเบราว์เซอร์

  • Mozilla Web Security Guidelines: เช็กลิสต์เบื้องหลังหัวข้อ 12 (TLS, คุกกี้, CSP, SRI, header)
  • Mozilla SSL Configuration Generator สำหรับการตั้งค่า load balancer และ proxy ของเรา
  • MDN HTTP Observatory: สแกน header ของเว็บเราและได้เกรด

มาตรฐานและข้อมูล

  • NIST SP 800-63B: รหัสผ่านและการยืนยันตัวตน
  • OSV.dev: ฐานข้อมูลช่องโหว่แบบเปิดที่ครอบคลุมทุก ecosystem

ฝึกปฏิบัติ

  • PortSwigger Web Security Academy: แล็บลงมือทำฟรีสำหรับการโจมตีเกือบทุกแบบในคู่มือนี้
  • OWASP Juice Shop: แอปที่จงใจให้มีช่องโหว่ เอาไว้ลองโจมตีในเครื่อง
  • รัน bin/brakeman และ bundle exec bundler-audit check --update กับแอปของเรา และแก้สัปดาห์ละหนึ่งรายการ

ทดสอบความรู้
