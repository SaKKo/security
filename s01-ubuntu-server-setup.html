Ubuntu Server Setup

You get a fresh Ubuntu 24.04 server. By the end it has a sudo user that logs in with your key, root login off, a firewall, Docker, and Node, Ruby and Python version managers. Pick how your provider gave you the server, then press ▶ play or go step by step.

    If you lock yourself out

    Every cloud provider has a web console (DigitalOcean "Recovery Console", AWS "EC2 Serial Console", Linode "Lish", Vultr "View Console"…). It's like a keyboard plugged into the server, so it works even when SSH or ufw is broken. Log in with the user's password (you set one in step 2), then undo the change: sudo ufw disable, or sudo rm /etc/ssh/sshd_config.d/00-hardening.conf && sudo systemctl restart ssh. If the user has no password, use the provider's "reset root password" or "rescue mode".
