Ubuntu Server Setup

Turn a fresh Ubuntu 24.04 server into a safe one: key login, no root, a firewall, Docker, Node, Ruby and Python. Pick a topic below, or press ▶ play to run them all.

    If you lock yourself out

    Open your provider's web console (it works without SSH), log in with the user's password, then undo: sudo ufw disable, or sudo rm /etc/ssh/sshd_config.d/00-hardening.conf && sudo systemctl restart ssh.

    Cheat sheet

    stepcommand
    connectssh -i key.pem user@IP (key must be chmod 600)
    updatesudo apt update && sudo apt upgrade -y
    new sudo useradduser ubuntu && usermod -aG sudo ubuntu
    switch usersu - ubuntu · back to root: exit · root shell: sudo -i
    add a key~/.ssh = 700, ~/.ssh/authorized_keys = 600, one key per line, append with >>
    harden sshd/etc/ssh/sshd_config.d/00-hardening.conf → sudo sshd -t → sudo systemctl restart ssh
    no sudo password/etc/sudoers.d/90-ubuntu with ubuntu ALL=(ALL) NOPASSWD:ALL, then sudo visudo -c
    firewallsudo ufw allow OpenSSH first, then 80/tcp, 443/tcp, sudo ufw enable
    firewall rulesufw status numbered · ufw delete N · ufw allow from IP to any port P proto tcp
